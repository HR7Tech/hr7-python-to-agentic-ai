# Day_13 - Beginner - Find - And - Fix - Your - Code - Summary 🐍

On Day 13 of Python bootcamp, I focused on **debugging** and **learning** how to systematically **find** and **fix** errors in my code. 

I practiced techniques such as **describing the problem clearly**, **reproducing bugs**, **stepping through code line by line**, and **using print() statements** and **debuggers to identify issues**. 

These skills were reinforced through exercises like debugging **Odd or Even**, **Leap Year**, and **FizzBuzz** programs, helping me write more accurate and reliable Python code.
