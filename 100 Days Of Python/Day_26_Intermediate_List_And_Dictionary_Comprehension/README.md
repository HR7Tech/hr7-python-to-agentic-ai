# Day 26 - Intermediate - List & Dictionary Comprehensions 🐍

## Topics Covered

- **List Comprehension** — Learned how to create lists in a single line using list comprehension instead of traditional loops, with optional conditions to filter results.

- **Dictionary Comprehension** — Learned how to build dictionaries in a single line by iterating over data and mapping keys to values, with optional filtering.

- **Small Exercises** — Practiced both list and dictionary comprehensions through small exercises to solidify understanding of syntax, filtering, and real-world use cases.

- **Iterating Over a Pandas DataFrame** — Used `iterrows()` to loop through a DataFrame row by row and extract values from specific columns to build a dictionary.

- **NATO Alphabet Project** — Built a project that takes a user's name as input and returns the NATO phonetic code for each letter using a CSV file, Pandas, dictionary comprehension, and list comprehension all together.
