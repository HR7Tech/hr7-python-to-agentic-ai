# Day_23 - Intermediate - Turtle - Crossing - Game - Summary 🐍


On Day 23 of Python bootcamp, I built the **Turtle Crossing Game**, a **capstone project** inspired by the classic arcade game **Frogger**. The main goal of the game is to help the turtle safely cross the road while avoiding moving cars.

I began by breaking down the **problem into smaller components** and then implemented the **player behavior**, allowing the turtle to move forward using keyboard input. 

Next, I created the **car behavior**, where multiple cars move across the screen at different positions to create obstacles for the player.

The game also includes **collision detection** to determine when the turtle hits a car, which ends the **game**. Additional logic was added to **detect** when the player **successfully** reaches the other side of the screen, allowing the game to progress to the **next level**.

 A **scoreboard system** was implemented to track levels and display the game over message when the player loses.

This project reinforced **problem decomposition**, **Object-Oriented Programming**, **collision detection**, and **building structured interactive games in Python**.
