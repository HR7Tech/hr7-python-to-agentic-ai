# Day 27 - Tkinter & GUI Development 🐍

## Topics Covered

- **History of GUI & Introduction to Tkinter** — Learned the background of Graphical User Interfaces and why Tkinter is Python's built-in standard library for building desktop GUI apps.

- **Creating Windows and Labels** — Learned how to create a basic window using `Tk()` and display text or images on it using the `Label` widget.

- **Buttons, Entry & Setting Component Options** — Learned how to create interactive widgets like `Button` and `Entry`, and how to configure their options using `.config()` and `.get()`.

- **Tkinter Layout Managers** — Learned the three ways to position widgets on a window — `.pack()` for stacking, `.place()` for exact coordinates, and `.grid()` for rows and columns.

- **Mile to Kilometers Converter Project** — Built a GUI app where the user enters a distance in miles, clicks a button, and the result is displayed in kilometers using Tkinter.

## More On Functions:

- **Default Values for Optional Arguments** — Learned how to set default values inside a function header so that arguments become optional when calling the function.

- **`*args` — Many Positional Arguments** — Learned how to accept any number of positional arguments inside a function using `*args`, which collects them into a tuple.

- **`**kwargs` — Many Keyword Arguments** — Learned how to accept any number of keyword arguments using `**kwargs`, which collects them into a dictionary.
