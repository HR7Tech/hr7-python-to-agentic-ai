# Day_17 - Intermediate - Benefits - Of - OOP - Summary 🐍

On Day 17 of Python bootcamp, I deepened my understanding of **Object-Oriented Programming** by creating my own **classes** and working with **constructors** using the **__init__() method**. 

I practiced defining **attributes**, adding **methods** to classes, and structuring programs using multiple interacting objects.

These concepts were applied through the multi-part **Quiz Project**, where I created a **Question class**, generated a list of question objects from **data**, and built a **QuizBrain class** to manage question flow, check answers, and keep track of the score. 

I also learned how **OOP** improves **modularity** and **scalability** by integrating new questions from the **Open Trivia Database**.

This project strengthened my ability to design structured, maintainable, and reusable Python applications using OOP principles.
