# Coffee Machine Project ☕️

**Project Overview**

On Day 15 of Python bootcamp, I built a **Coffee Machine** simulation using Python. This program mimics the basic functionality of a real coffee machine by allowing users to order drinks, process coin payments, manage resources, and track profit through a command-line interface.

**How the Coffee Machine Works**

1) The machine offers three drinks: Espresso, Latte, and Cappuccino

2) Each drink requires specific ingredients (water, milk, coffee)

3) The machine checks if enough resources are available before preparing a drink

4) Users insert coins to pay for their selected drink

5) The machine calculates change, updates profit, and deducts used resources

6) A report option shows remaining resources and total profit

7) The machine can be turned off using a command

**Concepts Applied**

- Dictionaries and nested dictionaries

- Functions with return values

- Global variables

- Conditional logic

- Loops (while)

- Resource management

- User input handling


**Learning Outcome**

This project helped me understand how to break down a real-world system into smaller logical components using functions and data structures. It also strengthened my ability to manage program state, handle user interactions, and build a complete console-based application.
