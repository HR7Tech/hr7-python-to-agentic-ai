# Day_14 - Beginner - Higher - Lower - Game - Summary 🐍

On Day 14 of Python bootcamp, I built the **Higher / Lower Game**, a console-based comparison game that tests the user’s ability to **guess** which option has more followers. 

The game logic is implemented in **main.py**, while **art.py** is used to display ASCII art for the game logo and versus symbol, and **game_data.py** stores the game data as a list of dictionaries containing names, descriptions, follower counts, and countries.

In this project, I applied concepts such as **functions with return values**, **loops**, **conditional logic**, **score tracking**, and the **random module**. 

The game continuously compares two randomly selected options, checks the user’s guess, updates the score, and ends when an incorrect answer is given. 

This project helped me improve my understanding of modular code structure, clean function design, and building interactive command-line games.
