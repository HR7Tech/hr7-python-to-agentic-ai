# Day 25 - Intermediate - Working with CSV Data & Pandas 🐍

## Topics Covered

- **Reading CSV Data** — Learned how to read `.csv` files in Python using the `csv` module and Pandas.

- **DataFrames & Series** — Understood the difference between a Series (1D) and a DataFrame (2D), and how to select, filter, and extract data from rows and columns.

- **Squirrel Census Data Analysis** — Analysed real-world squirrel data using Pandas — filtering by fur color, counting rows, and building summary DataFrames.

- **U.S. States Game Setup** — Set up the project with Turtle Graphics, loading a blank U.S. map as the background image.

- **Game Logic with CSV** — Used Pandas to load state names and coordinates, took user guesses via `textinput()`, and wrote correct answers directly onto the map.

- **Saving Data to CSV** — On exit, saved all missed states to `states_to_learn.csv` using `pd.DataFrame.to_csv()` as a personalised study list.
