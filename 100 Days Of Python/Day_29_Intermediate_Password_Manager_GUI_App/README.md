# Day 29 - Intermediate - Building a Password Manager App 🐍

## Topics Covered

- **Working with Images & Canvas** — Learned how to set up a Canvas widget in Tkinter and place an image on it at exact coordinates using `create_image()`.

- **Grid Layout & columnspan** — Used `grid()` layout manager to structure the UI neatly into rows and columns, and used `columnspan` to stretch widgets across multiple columns.

- **Saving Data to File** — Implemented functionality to save user input (website, email, password) into a `data.txt` file using Python's file handling with `open()` in append mode.

- **Dialog Boxes & Pop-Ups** — Used `messagebox` from Tkinter to show warning pop-ups for empty fields and confirmation pop-ups before saving data, using `showwarning()` and `askokcancel()`.

- **Generate Password Button** — Built a password generator that creates a strong random password and auto-populates the password entry field when the button is clicked.
