# Day 30 - Error Handling & JSON in Python 🐍

## Topics Covered

- **Try, Except, Else & Finally** — Learned how to handle errors gracefully using the full exception handling pattern, understanding when each block executes and why.

- **Raising Your Own Exceptions** — Learned how to manually trigger exceptions using `raise` to enforce rules and validate user input.

- **IndexError Handling** — Practiced catching `IndexError` when trying to access an index that doesn't exist in a list.

- **KeyError Handling** — Practiced catching `KeyError` when trying to access a key that doesn't exist in a dictionary, applied to real data like Facebook posts likes counter.

- **Exception Handling in NATO Project** — Upgraded the NATO Phonetic Alphabet project with proper exception handling to skip invalid characters instead of crashing.

- **JSON in the Password Manager** — Upgraded the Password Manager app to read, write, and update data using JSON format with `json.load()`, `json.dump()`, and `.update()` instead of plain `.txt` files.
