# Day_18 - Intermediate - Turtle - And - GUI - Summary 🐍

On Day 18 of Python bootcamp, I explored **Turtle Graphics** to create visual designs and practice coding concepts in a graphical way. I learned how to use the **Turtle documentation**, **import modules**, **install packages**, and **work with aliases**. 

I also practiced working with Python **tuples** and generating random **RGB colors** to add variety to the graphics.

I completed multiple **Turtle challenges**, including **drawing a square**, creating **dashed line**, **generating different shapes**, performing a **random walk**, and drawing a **spirograph**. These exercises built my understanding of loops, functions, and color handling in a graphical context.

The day culminated with the **Hirst Painting Project (100 Dots Painting)**, where I applied Turtle Graphics and random color generation to create a visually appealing dot painting, reinforcing creativity and programming skills together.
