# Day_21 - Intermediate - Snake - Game - Part 02 - Summary 🐍

On Day 21 of Python bootcamp, I completed **Part 2** of the Snake Game by adding more **advanced game mechanics** and improving the overall gameplay. 

I implemented **collision detection** with **food** so the snake grows when it eats, and created a **Scoreboard** class to track and display the player’s score.

I also added logic to **detect collisions** with the **walls and the snake’s own tail**, which ends the game when triggered. 

During this process, I further practiced **Object-Oriented Programming** concepts, including **class inheritance**, to structure the game components more effectively. 

Additionally, I learned how to **slice lists and tuples** in Python, which is useful when working with sequences of data.

Completing this project strengthened my understanding of **game logic**, **collision detection**, **OOP design**, and **managing multiple interacting objects within a program.**
