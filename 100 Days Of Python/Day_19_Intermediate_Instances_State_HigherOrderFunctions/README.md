# Day_19 - Intermediate - Instances - State - Higher Order Functions - Summary 🐍

On Day 19 of Python bootcamp, I learned about **higher-order functions** and **event listeners**, allowing programs to **respond** to **user input** such as **key presses**. 

I explored how **object state** works and how **instances** maintain their own data within a program. I also gained a clear understanding of the **Turtle coordinate system** and how positioning works on the screen.

These concepts were applied through interactive projects, including building a **Turtle Race game** using event handling and object movement logic. 

I also completed the **Etch-A-Sketch challenge**, where keyboard controls were used to move the turtle and draw dynamically on the screen.

This day strengthened my understanding of **event-driven programming**, **object behavior**, and **building interactive graphical applications using Python**.
