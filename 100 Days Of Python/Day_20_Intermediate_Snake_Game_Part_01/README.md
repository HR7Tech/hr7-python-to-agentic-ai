# Day_20 - Intermediate - Snake - Game - Part 01 - Summary 🐍

On Day 20 of Python bootcamp, I started building the **Snake Game (Part 1)** using **Turtle Graphics**. I set up the **screen**, created the initial **snake body**, and implemented **animation logic** to move the snake segments smoothly across the screen.

I refactored the program using **Object-Oriented Programming** by creating a dedicated **Snake class**, improving code organization and scalability. 

I also implemented **keyboard controls** to allow the user to change the snake’s direction using keypress events.

This project strengthened my understanding of **screen updates**, **object movement**, **event handling**, and **OOP design principles**. 

The day concluded with an important reminder that **programming is about problem-solving and logical thinking, not memorization.**
