# Day 29 - Building a Pomodoro Timer App with Tkinter ⏳🐍

## Topics Covered

- **Working with the Canvas Widget** — Learned how to use Tkinter’s `Canvas` widget to draw shapes, place text, and organize UI elements inside the application window.

- **Adding Images to Tkinter** — Learned how to import and display images in a Tkinter app using `PhotoImage`, making the interface more visually appealing.

- **Challenge - Complete the Application UI** — Practiced building the full user interface by arranging labels, buttons, images, and layout elements to complete the timer app design.

- **Adding a Countdown Mechanism** — Learned how to create a live countdown timer using Tkinter’s `after()` method to update the timer every second.

- **Dynamic Typing Explained** — Understood how Python handles variable types dynamically, allowing variables to change data types during runtime.

- **Setting Different Timer Sessions and Values** — Learned how to switch between work sessions, short breaks, and long breaks by applying different countdown durations.

- **Adding Checkmarks and Resetting the Application** — Implemented progress tracking with checkmarks after completed sessions and added a reset feature to restart the timer.
