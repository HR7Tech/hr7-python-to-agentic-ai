# Day_16 - Intermediate - Object - Oriented - Programming - Summary 🐍

On Day 16 of Python bootcamp, I explored **Object-Oriented Programming (OOP)** and learned why it is essential for structuring **larger and more scalable applications**. 

I understood how **OOP** works using **classes** and **objects**, and how they help organize code by grouping related data and behavior together.

I practiced creating **classes**, constructing **objects**, accessing and modifying **attributes**, and calling **methods**. 

I also learned how to install and use **external Python packages** through **pip** and **PyPi**. 

These concepts were applied by **rebuilding the Coffee Machine project** using OOP principles, improving code structure, readability, and maintainability.
