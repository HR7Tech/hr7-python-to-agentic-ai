# Day_22 - Intermediate - Pong - Game - Summary 🐍


On Day 22 of Python bootcamp, I built the **classic Pong Game** using **Python** and **Turtle Graphics**.

The project involved setting up the **main game screen**, **creating paddles** that respond to keyboard input, and implementing the **core mechanics** of the game.

I created separate **classes** for the **paddles** and the **ball**, applying **Object-Oriented Programming** to keep the code **modular** and **organized**. 

The ball **movement** and **bouncing logic** were implemented to simulate **realistic gameplay**, including collisions with the paddles and the top and bottom walls.

Additional game logic was added to **detect** when the ball goes **out of bounds**, update the **scoreboard**, and gradually **increase** the ball **speed** to make the game more **challenging**.

This project strengthened my understanding of event handling, collision detection, and building interactive games using structured Python code.
