# Day_24 - Intermediate - Files - Directories - Paths - Summary 🐍


On Day 23 of Python bootcamp, I learned how to work with **files**, **directories**, and **file paths** in Python. 

I practiced **opening**, **reading**, and **writing files** using the **with** keyword, which ensures files are handled safely and closed automatically.

I applied these concepts by enhancing the **Snake Game** to store and update a high score using file handling. This allowed the score to persist even after the program is **restarted**. 

I also explored the difference between **relative** and **absolute** file paths, improving my understanding of how Python locates files within a project.

These concepts were further reinforced through the **Mail Merge Project**, where I read names from a file and generated personalized letters. 

During this challenge, I used string and file methods such as **.strip()**, **.replace()**, and **.readlines()** to process and manipulate file content efficiently.

This day strengthened my understanding of **file handling**, **path management**, and **automating repetitive** tasks using Python.
